# ZERO-BUILDER v4.4 — Motion Studio + AI Engineer

An AI product studio aimed at **Motionsites / Layers / Awwwards-class websites**, with full-stack product mode still available.

## What it builds

- **Cinematic static sites** — HTML/CSS/JS + GSAP ScrollTrigger + Lenis + optional Three.js/WebGL + video heroes  
- **React + Vite** SPAs when you need component apps / R3F  
- **Next.js full-stack** when Auth / Database / API / Payments are selected  

## Run locally

```bash
npm run dev
```

Open `http://localhost:4173`.

## Motion Studio workflow (recommended for premium websites)

1. Configure a strong model in Settings (Pro / Sonnet / GPT-4o preferred over Flash).
2. Type a short idea **or** open the **Prompt Library** (template button).
3. Click **Enhance** — the **Prompt Engineer** expands it into a studio-grade brief (hero treatment, motion systems, anti-patterns).
4. Select quality **Motion Studio**.
5. Keep framework on **HTML/JS** for cinematic marketing sites.
6. Generate → agents run: Prompt Engineer → Plan → Brand → Design → Media → WebGL (if needed) → Scenes → Motion → Review (≥ 92).
7. Export ZIP.

### Example short prompt

`luxury real estate website with video hero and scroll film`

Enhance will turn this into a long Motionsites-style brief; Generate builds scroll scenes, not a purple SaaS template.
